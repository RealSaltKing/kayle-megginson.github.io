What I built

A word game that depends on clear feedback and careful state.

This project recreates the familiar Wordle loop while keeping the logic readable: guesses, keyboard input, tile feedback, and game state all have to stay in sync.

  • Built the game board, on-screen keyboard, and answer-checking flow.
  • Managed visual feedback for correct, present, and missing letters.
  • Used a compact interface to practice small details that make interaction feel better.
